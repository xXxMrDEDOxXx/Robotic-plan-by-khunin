# แบบฟอร์มคะแนนแบบทดสอบวัดระดับ

> กรอกคะแนนที่ได้ของทุกข้อหลังตรวจด้วยไฟล์เฉลย แล้วคัดลอกทั้งตารางส่งให้ผมในแชต ผมจะคิดร้อยละรายแขนงและรายหมวด แล้วปรับแผนตามเกณฑ์ข้อ 5.5 และ 5.6 ของตอนที่ 9

วิธีกรอก

1. ก่อนเปิดเฉลย ให้กรอกคอลัมน์ "คะแนนที่คาด" ของทุกข้อก่อน ค่านี้ใช้วัดว่าการประเมินตัวเองตรงกับคะแนนจริงแค่ไหน
2. ข้อที่ไม่ได้ทำหรือเขียนว่าไม่รู้ ให้กรอก 0
3. ข้อที่เห็นเฉลยก่อนทำ ให้กรอก 0 และเขียน "เห็นเฉลย" ในหมายเหตุ
4. ข้อ 7.3 และ 11.1 ให้ระบุในหมายเหตุว่าทำแบบหลักหรือแบบทดแทน
